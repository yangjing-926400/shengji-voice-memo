# 声记 v0.1

一个本地优先的语音备忘录 PWA。第一版包含：

- 录音并保存在浏览器 IndexedDB
- 浏览器语音识别
- 本地规则自动归组
- 语音搜索和来源记录
- 离线打开、本地数据保存、PWA 安装

## 本地运行

双击 `start-app.command`，或者运行：

```bash
python3 server/server.py
```

然后打开 `http://127.0.0.1:4174/`。

带示例数据的界面：

```text
http://127.0.0.1:4174/?demo=1
```

## 当前限制

- 语音识别依赖浏览器能力，推荐最新版 Chrome 或 Safari。
- 自动归组目前是本地关键词和相似度规则，不是云模型。
- 语音转文字默认使用 Mac 上的 Apple 中文离线识别服务。
- 没有跨设备同步和云端备份。
- 第一次录音需要授权麦克风。
- 手机远程访问本地 HTTP 服务时，浏览器可能禁止麦克风；正式体验需要 HTTPS 部署。


## iPhone 安装测试

1. 用 Safari 打开 HTTPS 地址，不要使用微信内置浏览器。
2. 点击 Safari 底部“分享”按钮。
3. 选择“添加到主屏幕”。
4. 从主屏幕打开“声记”。
5. 第一次录音时允许麦克风权限。

当前版本已按以下 iPhone 逻辑屏幕尺寸检查过：320×568、375×667、375×812、393×852、430×932、440×956。

## 测试地址说明

临时 HTTPS 隧道适合真机测试，关闭 Mac、服务器或隧道后地址会失效。长期使用需要部署到 GitHub Pages、Cloudflare Pages 等固定免费 HTTPS 地址。

## 手机测试重点

- 是否能成功添加到主屏幕
- 录音按钮是否始终可见
- 麦克风权限是否正常弹出
- 录音停止后是否生成文字和分组
- 语音搜索是否能正确启动麦克风
- 从主屏幕打开后数据是否仍然存在


## 原生 iOS 版

原生 SwiftUI 工程位于 `ios/Shengji.xcodeproj`，使用 iPhone 本机 Apple 语音识别，不依赖 Mac 后台。

安装步骤见 `ios/README.md`。
