# 声记快捷指令

`声记.shortcut` 会执行：

1. 调用 iPhone 听写，把你说的话转成文字。
2. 对文字进行 URL 编码。
3. 打开声记网页并传回文字。
4. 声记自动保存、归组并加入搜索。

## 安装到 iPhone

1. 在 Mac Finder 中右键 `声记.shortcut`。
2. 选择“共享”->“隔空投送”->你的 iPhone。
3. 在 iPhone 上点击“添加快捷指令”。
4. 运行“声记”，或对 Siri 说“声记”。
5. 说完以后点完成，文字会自动保存到声记。

## 更换服务器地址

```bash
./build.sh https://你的固定地址/ 声记.shortcut
```

重新生成后，再通过隔空投送到手机安装。
